# Site Assets

- `overview.pdf` is the overview figure from the current manuscript, copied byte-for-byte from `docs/assets/overview.pdf`. `overview.png` is its rendered preview and matches `docs/assets/overview.png` byte-for-byte.
- `data-profiles.png` illustrates temporal and contextual dataset characteristics. It is a byte-identical copy of `docs/assets/data-profiles.png`.
- `castworld-mark.svg` and `favicon.svg` are identical copies of the original CastWorld mark in `docs/assets/brand/`. Its three-color globe and W-shaped signal represent context-rich data, state-adaptive interaction, and decision-centric evaluation.
- `lucide.min.js` is the unmodified Lucide 0.468.0 UMD distribution from `https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js`.
- `LUCIDE_LICENSE` is the upstream license file, retained with the icon distribution.

No task inputs, target histories, future labels, model credentials, or private evaluator files are stored in this directory.
